Story Studio privacy policy

Last updated: 20 November 2026

Story Studio is a personal tool that its owner uses to make history videos and upload them to the owner's own YouTube channel. It is not offered to the public.

What it accesses

With the owner's permission, Story Studio uses the YouTube Data API to upload videos, set thumbnails and read basic channel details for the owner's own channel. It does not access anyone else's account.

What it stores

The sign-in key from Google is stored only as an encrypted secret in the owner's own GitHub project, and the app settings are stored only on the owner's device. Story Studio does not collect, sell or share personal data, and it does not use advertising or tracking.

YouTube and Google

Story Studio uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and the Google Privacy Policy applies. You can remove Story Studio's access at any time at myaccount.google.com/permissions.

Contact

Questions can be raised as an issue on the project's GitHub page.
