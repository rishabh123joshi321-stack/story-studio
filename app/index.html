Settings

Fix problems

Something not working? Run a check-up. The app looks for stuck or failed videos, broken video files, sign-in problems and old warnings, and repairs what it can with one tap.

Quick fixes

Connect to your GitHub project

Your access key is saved only on this tablet. It can only touch your one video project, and you can cancel it on GitHub at any time.

Connect YouTube

Do this once, after the Google setup steps. Videos you approve then upload to your channel as Private, and you make them Public in YouTube Studio.

Redirect address to give Google:

Until Google finishes its free review of your app, videos it uploads are locked Private. Keep automatic upload OFF for now: approved videos then show Download and Copy buttons in the Queue so you can post them from the YouTube app.

Daily target

Intro and end screen

Long videos start with a 3-second title card with your channel name, and end with a 10-second "Thanks for watching" screen. Add YouTube's end-screen boxes to it in Studio. Shorts never get them. Background sounds (fire, crowds, sea...) are added to every video automatically.

How often the picture changes

For long videos. More picture changes keep viewers watching, but each picture uses some of the free daily allowance (about 170 a day), so long videos take longer to make.

Narrator

When the script quotes a historical figure's real words, a second, contrasting voice reads the quote.

Pronunciation list

Teach the narrator tricky names. Write how it should sound, for example Tenochtitlan → Teh-notch-teet-lahn.

Subtitle languages

Each new video also gets subtitles, a title and a description in these languages (up to 4), so viewers worldwide can follow. English subtitles are always made.

Caption font

The font for the words shown on screen in your videos. Tap one; new videos use it.

Try it without connecting

Demo mode saves videos on this tablet only, so you can try the screens before setup is finished.
